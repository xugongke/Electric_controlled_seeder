# 组态屏全画面控件配置清单 (2026-09-28 版)

配套标签表: 标签表.csv (140个, 全小写, 导入前先清空旧标签)。
与 lwmap.lua 逐条核对; 所有文本控件字符编码统一 GB2312。
**文本控件字数**: LW字符串 1字=16位=2字节(1个GB2312汉字或2个ASCII字符),
控件"变量字数"按下表配置, 多字串间按规划留隔离区勿重叠。
约定: 数值输入=勾"启用输入+弹出键盘"; 位设置按钮=写1触发(Lua自动复位);
功能按钮=开/关对话框或切画面, 配执行通知写LW(值=1)。

## 画面5 测试诊断页 (2026-09-28重设, 对齐QT formtest)

**输入状态 = 15盏具名位灯**(绑 td_input 的位, 绿=触发; 报警红字绑 td_warning 同位):

| 位 | 名称 | 位 | 名称 |
|---|---|---|---|
| bit0~3 | 零位开关1~4 | bit8 | 压力 |
| bit4 | 自动供种 | bit9 | 风机 |
| bit5 | 预留 | bit10 | 脚踏板 |
| bit6/7 | 钢索1/2 | bit11 | 初始化 |
| bit12 | 北斗 | bit13/14 | 零位开关5/6 |

**输出控制 = 16个一键翻转按钮**(点按=读当前CtrlState位取反后0x09下发):

| 标签 | 设备 | 标签 | 设备 |

| td_sw0 / td_sw1 / td_sw2 / td_sw3 / td_sw4 | 阀1~5(CtrlNo0~4) | td_m1 / td_m2 / td_m3 / td_m4 | 播种盘1~4电机(CtrlNo16~19) |

| — | — | td_m6 / td_m7 | 播种盘5/6电机(CtrlNo21/22) |

**状态回显**: td_ctrl(u32只读, 阀位0~9+电机位16~22, 可配位灯组) + 计数显示:
