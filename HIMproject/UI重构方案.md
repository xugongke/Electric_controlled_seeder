# 组态屏界面重构方案 (VisualHMI, 800×480 电阻屏)

依据 hmi-doc.gz-dc.com 控件调研(2026-09-23) + 现有9画面结构, 为地图网格可视化
与农机图标留位。目标: 减少重复、统一状态呈现、大地图可拖动、长列表可滑动。

---

## 一、控件选型速查(调研结论)

| 控件 | 本方案用途 |
|---|---|
| **嵌入画面** | ①全局状态栏一处制作、所有画面复用(无母版机制下唯一官方复用途径) ②地图大画布视口: 视口内显示最大10000×10000逻辑画面, 手指拖动平移, 偏移/目标画面均有LW可读写 |
| 滑动画面 | 横向整页翻页容器(手机桌面式), 非自由滚动——本方案暂不用, 滚动地图走嵌入画面 |
| **动态绘图** | 地图网格自绘(on_draw内draw_rect/draw_text), 数据变化时redraw(), 勿定时整刷 |
| 图标控件+wgt_set_pos | 农机图标层: 叠在动态绘图上方按Z序, 移动只挪控件不重绘画布(5Hz零开销) |
| **数据记录控件** | 历史/日志页表格: 手势滑动滚动、固定列、行选中事件(Addr+4写行号)、Lua拼串刷新 |
| 多状态灯 | 链路灯(0x1013)/运行状态/22路输入状态灯阵(每状态可映射图片) |
| 位设置按钮 | 测试页阀/电机控制矩阵 |
| 进度条/仪表 | 任务完成度、速度表 |
| 虚拟键盘 | 拼音中文输入(任务名等), 弹出式可复用 |
| 进入动画 | 画面切换动效(控件属性, 非API) |

实测教训(沿用): LW>=0x1000存储器地址均可正常读写(早期"0x1016禁写"为误判,
2026-09-23更正); tip字符串区0x101C~0x1023共8字勿占; i32占偶地址两字。

## 二、全局架构

```
画面号规划(lwmap.LW.SCREEN 同步增补):
  0~8    现有画面(主页/连续播种/参数/测试诊断/任务向导/历史/日志;
         画面1小区参数与画面3AB线已于2026-09-23删除, 号不复用)
  20     STATUSBAR  状态栏画面(800×40, 仅作嵌入内容, 不可直达)
  21     MAPCANVAS  地图大画布(尺寸按地图动态, 仅作嵌入内容)
```

**每个功能画面统一结构**: 顶部0~39px=嵌入画面(目标20)状态栏; 40~479px=内容区。

**状态栏画面(20)内容** [800×40]:
```
┌────────────────────────────────────────────────────────────┐
│ [链路灯0x1013] [运行灯0x1019] 版本0x1024(6字) │ RTC时间控件 │ 作业摘要0x1030(16字) │
└────────────────────────────────────────────────────────────┘
```
- 链路灯=多状态灯绑0x1013 (0:红"通信中断"图 / 1:绿"在线"图)
- 运行灯=多状态灯绑0x1019 (0停止红/1准备黄/0x81播种绿)
- 版本/摘要=文本控件(已有地址, 状态栏复用)
- Lua侧无改动(地址已存在), 画面做好即全局生效

### 画面22 AB线对话框(2026-09-24新增, 仅作弹出内容)
```
┌─────────── 保存AB线 / 查看AB线 ───────────┐
│ 名称: [文本输入(虚拟键盘) 读写0x1D02]       │  ← 保存模式可编辑
│ A点: 纬度/经度(0x1500/0x1502)  B点: …     │  ← 显示控件绑 LW.AB 区
│ 方向角/StartState/CalcDirFlag/OffLen…      │    (0x23应答自动填充)
│ [确认保存=功能按钮:关闭对话框+通知0x1D11=1]  │
│ [取消=功能按钮:关闭对话框+通知0x1D12=1]      │
└──────────────────────────────────────────┘
```
- 打开: 画面上"保存AB线/查看AB线"按钮=功能按钮(打开对话框,目标22,蒙版50~70)
  +执行通知写 LW.ABP.req(1保存/2查看) → Lua发0x23采集, 应答填显示
- 模式文案切多状态灯绑 LW.ABP.mode(0保存/1查看)

### 画面21 地图大画布(新增, 仅作嵌入内容)
- 逻辑尺寸 = 列数×CW × (排数×RH + 过道折算), CW=120 RH=95(触摸友好的小区格),
  上限按 40列×30排=4800×2850 (嵌入画面上限10000内)
- 单个动态绘图控件铺满画布, on_draw(screen=21, control=画布ID)绘制:
  - 小区色块: 未开始灰/已下发蓝/完成绿/中断橙红/不播深灰 + draw_text小区号
  - 排/列标签沿边绘制(对照QT表头语义: 显示排号=总排-内部行)
- 农机图标=图标控件叠在画布(目标画面21内), jobrun每帧0x21算位置→wgt_set_pos
- 重绘时机: 块状态变化/jobrun启停/地图载入时 redraw(); **不随农机移动重绘**
- Lua侧新增 mapdraw.lua(纯函数: 地图+状态+农机位置→绘制指令序列) + on_draw薄壳
